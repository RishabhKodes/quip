# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** option in the repository Security tab
to submit a private advisory. Include affected versions, reproduction steps,
impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. A fix timeline depends
on severity and reproducibility.

## Supported Versions

Security fixes are applied to the latest revision of the default branch. The
project does not currently maintain older release branches.

## Sensitive Data

Never include API keys, page contents, access tokens, or production URLs with
embedded credentials in reports, issues, logs, screenshots, or test fixtures.
